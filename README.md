# 🎨 Matheus de Castro | Arts & Backend Dev Portfolio

Este é o repositório do meu portfólio pessoal, um espaço desenvolvido para unir o rigor lógico da engenharia de software com a sensibilidade estética da arte. Como estudante de TI na UFRN, utilizo este projeto para centralizar minhas soluções de arquitetura de backend, automações e pipelines inteligentes.

> "O código deve ser tão elegante quanto a arte."

## 🌐 Acesse o site

O portfólio está disponível em: **[matheusdecastro.com](https://matheusdecastro.com/)**

## 🚀 Tecnologias & Ferramentas

Para garantir alta performance, modularidade e experiência refinada:

* **Core & Frontend:** React 19, Vite, JavaScript (ES6+), TypeScript, HTML5, CSS3, Markdown.
* **Backend & Linguagens:** Python, C#, Java, C++, PostgreSQL, .NET / ASP.NET, FastAPI, Spring Boot.
* **Data Science & ML:** PyTorch, Scikit-Learn, Pandas, NumPy.
* **Ambiente & Ferramentas:** Ubuntu Linux, Git, VS Code.
* **Estilização & UI:** CSS puro com variáveis customizadas, suporte a glassmorphism (vidro fumê com backdrop-filter), grids responsivos e efeitos reativos neon.

---

## 🛠️ Funcionalidades e Destaques

* **Single Page Application (SPA) Reativa:** Navegação instantânea por estados entre a visão profissional/acadêmica e a galeria artística (`Hobbies`), sem recarregar a página.
* **Galeria de Artes com Lightbox:** Visualização em tela cheia com navegação por setas (anterior/próximo) e suporte a touch.
* **Linha do Tempo de Experiências:** Abas dinâmicas com navegação por clique e setas de paginação, com suporte a rolagem horizontal suave no mobile.
* **Design Responsivo & Otimização Mobile:** Layout refinado com Safe Area para dispositivos móveis, tablets e monitores ultrawide.
* **Deploy Automatizado:** Pipeline integrado com GitHub Pages e domínio customizado (`CNAME`).

## 📦 Scripts Disponíveis

No diretório do projeto, você pode executar:

* `npm run dev`: Inicia o servidor local de desenvolvimento (`localhost:5173`).
* `npm run build`: Compila e otimiza a aplicação para produção na pasta `dist`.
* `npm run preview`: Visualiza localmente o build de produção.
* `npm run deploy`: Executa o build e publica a pasta `dist` na branch `gh-pages`.
